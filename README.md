# 90-Day Cloud & DevOps Engineering Journey

A structured, hands-on 90-day roadmap designed to master core DevOps competencies, cloud architecture, Infrastructure as Code (IaC), containerization, CI/CD automation, and production observability.

---

## 🗺️ 90-Day Curriculum Roadmap

| Phase | Days | Domain Focus | Key Topics & Deliverables |
| :--- | :--- | :--- | :--- |
| **Phase 1** | Days 01–15 | **Linux & Bash Scripting** | File systems, permissions, process management, user administration, systemd, SSH, automation scripts |
| **Phase 2** | Days 16–25 | **Networking & Version Control** | OSI/TCP-IP models, DNS, subnets, routing, firewalls, advanced Git workflows, branching strategies |
| **Phase 3** | Days 26–40 | **Cloud Fundamentals (AWS)** | IAM, VPC, EC2, S3, RDS, security groups, load balancers, auto-scaling, CLI automation |
| **Phase 4** | Days 41–55 | **Containers & Orchestration** | Dockerfile optimization, multi-stage builds, Docker Compose, Kubernetes architecture, Pods, Deployments, Services |
| **Phase 5** | Days 56–68 | **Infrastructure as Code (IaC)** | Terraform state management, modules, providers, variables, provisioning multi-tier cloud infrastructure |
| **Phase 6** | Days 69–78 | **CI/CD Automation** | GitHub Actions / Jenkins pipelines, linting, automated testing, artifact management, automated deployments |
| **Phase 7** | Days 79–85 | **Observability & Reliability** | Prometheus metrics, Grafana dashboards, log aggregation, alerting, incident response postmortems |
| **Phase 8** | Days 86–90 | **Capstone & Interview Prep** | Production end-to-end deployment, resume portfolio artifacts, architecture reviews, interview mock prep |
